# Stacked Bar Plot of HLA Allele Frequencies

This project generates stacked bar plots showing the frequency distribution of HLA class I alleles (HLA-A, HLA-B, HLA-C) from allele frequency data.

## Files

- `StackBarPlot.Rmd`: R Markdown file that reads allele frequency data, groups rare alleles (<5%) as "Others", and visualizes the frequencies in stacked bar plots using `ggplot2` and `viridis`.
- `HLA_LocusA_Allele_Frequencies.txt`, `HLA_LocusB_Allele_Frequencies.txt`, `HLA_LocusC_Allele_Frequencies.txt`: Input tab-delimited text files containing allele frequency data for each locus.
- `HLA_A_plot.pdf`, `HLA_B_plot.pdf`, `HLA_C_plot.pdf`: Output plot PDFs generated by the R Markdown code.

## Methods

- Alleles with frequency < 5% are combined and labeled as "Others"
- Frequencies are summed and plotted using stacked bar plots
- Color palette: Viridis
- Output is saved as PDF for each HLA locus
